# Cpp-Core-CS-Interview-Guide

这是一个持续更新中的计算机系统、计算机网络与 C++ 核心知识点合集。仓库的目标不是简单罗列八股答案，而是尽量用易懂、系统、贴近底层实现的方式，把面试中高频出现的知识点讲清楚：它是什么、为什么需要它、底层大致怎么做、面试时容易追问到哪里。

对于正在准备 后端开发、系统开发、游戏开发 等方向面试的朋友，本系列会覆盖我在面试中遇到过的考点，以及围绕这些考点展开的相关拓展。读完后，你应该能更从容地面对大部分操作系统、网络、C++ 语言层面的追问。对于想深入学习计算机基础的朋友，本系列也会尽量从系统视角解释概念之间的关系，帮助你把零散知识连成一张更完整的图。

## 适合谁阅读

本系列并不是面向完全零基础同学的速通材料，也不是按期末考试或教材章节去组织的复习提纲。它更适合已经写过一些代码、了解基本计算机系统概念，并且希望把底层基础补扎实的朋友。

如果你正在准备面试，建议把它当作“理解型八股”来读：不要只背结论，多关注每个机制背后的原因和代价。如果你是为了系统学习，也可以按合集顺序慢慢看，把文中的例子、图示和代码片段结合起来理解。

## 阅读建议

每篇文章通常会先讲概念，再讲机制，最后补充面试中容易被追问的细节。建议阅读时多问三类问题：

1. 这个机制解决了什么问题？
2. 它依赖哪些底层结构？
3. 它带来了哪些代价或边界？

这样学到的内容会比单纯背答案更稳定，也更容易在面试追问中展开。
